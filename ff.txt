🔹 Checklist “What’s missing in core?”
1️⃣ Environment & Config

 .env.example file يوضح كل الـ variables المطلوبة

 Validation قوية للـ settings (مثل SECRET_KEY mandatory)

 إمكانية تغيير environment بسهولة (dev/test/prod)

 Default values مناسبة بس بدون sensitive info

2️⃣ Security

 OAuth2PasswordBearer / HTTPBearer موجود في security layer (لو هتعمل auth endpoints)

 Logging للأخطاء في password verification

 Custom exceptions لـ decode_token بدل رمي JWTError مباشرة

 Optional: refresh token logic (لو هتعمل login sessions أطول)

3️⃣ Database

 Migrations setup (Alembic)

 Enum type validation للـ db query parameter

 Connection pooling tuning (max_connections, timeout) حسب حجم المشروع

 Optional: Async context manager helpers للـ DatabaseFactory

 Optional: Retry mechanism لو connection failed

4️⃣ Logging

 موحد لكل core: DB rollback, JWT failure, password verification failure

 ملف logger.py في core يستخدم logging module

 Optional: structured logging + levels (INFO, WARNING, ERROR)

5️⃣ Testing / Mocking

 Fixtures / mock DB for testing endpoints

 Ability to override settings for test environment (مثلاً SQLite in-memory)

6️⃣ Miscellaneous

 Comments/docstrings لكل class / function

 Type hints كاملة لكل function

 Optional: constants.py (مثل static URLs, default values)
